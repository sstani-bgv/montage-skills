## Правила, которые нельзя нарушать

1. **Светлая тема.** Фон `--paper` (#F6F7F9), текст `--ink` (#14161A). НЕ тёмный.
2. **Один яркий акцент на экране.** Синий `--blue` — по умолчанию. Коралловый `--coral` — только боль/срочность. Жёлтый `--mark` — highlighter ЗА словом, не фон блоков.
3. **Два шрифта.** `Unbounded` — ТОЛЬКО крупные акценты (обложки, титулы, гигантские цифры, кегль ≥70px). `Onest` — всё остальное, включая лейблы капсом с трекингом.
4. **Минимум 24px** для основного текста (читаемость в видео).
5. **Схемы:** одна схема — одна мысль, не больше 3–4 элементов (зритель считывает за 2 сек). Синим красим только тот элемент, о котором говорим сейчас. Декоративных стрелок нет — связи только отрезками. Внутри блоков схем — сетка-миллиметровка (`.grid-paper`).
6. **Иконки:** монолинейная геометрия, линия 2px, круг/квадрат/ромб/кольцо/искра. Без объёма и эмодзи.
7. **Стекло (liquid glass)** — ТОЛЬКО поверх видео, максимум одна панель в кадре. На светлый фон презентации не ставить. Текст всегда `--ink`, акцент синий. Тёмный кадр → тот же рецепт на `--glass-dark` с белым текстом.

## Типографическая шкала

| Роль | Размер | Шрифт |
|---|---|---|
| Обложка / титул | 70px | Unbounded 700 |
| Заголовок слайда (H1) | 54px | Onest 800 |
| Подзаголовок (H2/лид) | 38px | Onest 700 |
| Основной текст | 24px | Onest 400 |
| Кикер / лейбл | 15px | Onest 700, uppercase, letter-spacing .14em |

Трекинг: крупный кегль — отрицательный (−0.02…−0.03em), капс-лейблы — положительный (+0.1…+0.16em).

## Компоненты

- **Кнопки:** заливка `--blue` / белая с `--line` / текстовая. Радиус 10–14px.
- **Бейджи и чипы:** пилюля (радиус 30px), тонкая рамка `--line`, тинт `--blue-100` / `--coral-100`. Чип «● Дословно» — точка + текст.
- **Карточка-шаг:** большая цифра, заголовок, поясняющий текст; `--surface`, радиус 18px, `--shadow`.
- **Цифра/статистика:** гигантское число Unbounded + короткая подпись Onest.
- **Цитата:** гигантская «« », текст, атрибуция «— Имя».
- **Медиа-слоты:** заштрихованные рамки с меткой («слот под видео · 16:9», «B-roll»), пары «Было / Стало».

## Движение (раздел 06 системы)

Канонический словарь анимаций — воспроизводить именно его:

- **Rise** — слова заголовка поднимаются снизу (по словам, каскад).
- **Fade in** — чипы, бейджи.
- **Marker wipe** — жёлтая заливка `--mark` протягивается за ключевым словом.
- **Strike** — зачёркивание.
- **Float** — плавающие иконки.
- **Draw** — рисование линий (SVG stroke-dashoffset).
- **Count-up** — счётчики цифр.
- **Typewriter** — печать консоли.

**Каскад — задержки 0.1–0.2 с.** Элементы появляются по сценарию рассказа. Демки проигрываются один раз при входе.
