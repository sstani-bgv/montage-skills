# Стиль v4 — «презентация с картинками» (стиль по умолчанию с сентября 2026)

**Это стиль, который автор одобрил словами «вообще идеальный» и просил повторять в следующих
роликах один в один.** Если пользователь не сказал иначе — все вставки делаем так. Старые приёмы
из `techniques.md` (PiP-морф, zoom-through, карусель глав…) — допустимые акценты, но не основа.

Эталонная сборка: 40-минутный стрим — новое интро + 34 вставки.
Эталонные сцены — `recipes/v4/`.

## 3. Визуальные константы

- Палитра — дизайн-система канала (`design-system.md`): бумага `#F6F7F9`, белые карточки, `--ink`, один синий `#2E58EA` на экран, коралл для боли (текст `#C8322A` — `--coral` на `--coral-100` не проходит контраст), жёлтый `--mark` — маркер за словом.
- **Рубрика (кикер) — не пилюля.** Синяя черта 44×5 + капс 24px с трекингом `.16em`, без фона и рамки (`.kicker` в `assets/style-v4/common.css`). Пилюлю автор назвал «слишком круглой хреновиной».
- **Никаких служебных подписей** «Имя · стрим про …» и лоуэр-третей с именем.
- Кегли: заголовок full 100px, панели 76–92px; подписи **≥30px**, чипы **≥34px**, названия карточек ≥40px, ничего мельче 26px (кроме рубрики 24px).
- **Картинка-герой почти в каждой сцене** (кроме kinetic и чистых схем). Генерация — Codex (`scripts/gen_images.sh`), единый стиль-хвост: *photorealistic 3D render, premium product-shot look, soft studio lighting, gentle contact shadow, pure white background, single cobalt-blue (#2E58EA) accent detail, no text*. В промпте — только объект-метафора одной фразой («a brass key tied to a blank cobalt-blue luggage tag» для JSON ключ/значение). Белый фон → альфа (`scripts/alpha.py`). Одна картинка — одна сцена, не повторять в соседних.
- Носители смысла: чипы (`.chip`, активный — синяя заливка `.chip-on`), шаги с номерами (активный синий, пройденные — синяя обводка/галочка), карточка «серая = как было / синяя = как надо», штамп Unbounded в коралловой рамке («ОТКАЗ», «НЕУДОБНО», «1 ПРОМПТ»), зачёркивание коралловой линией, счётчик `countUp`, маркер за словом.

## 4. Движение

Хелперы `assets/style-v4/common.js`: `heroIn` (двухступенчатый вход expo.out .45 → линейная досадка .8, блюр 16→0), `rise` (пословно opacity/blur/y, stagger .12), `chipIn` (back.out влёт + досадка), `countUp`. Сквозной дрейф `#stage` 1→1.035, пятна ползут, герой плывёт — статичных кадров нет.
- Текст опережает голос на 0,15–0,35 с. **Тайминги — по пословной разметке** (Groq whisper, `timestamp_granularities[]=word`), не по «опорным словам» спеки: они плывут на 0,5–3 с.
- Панель достраивается по словам; собранное состояние держится ≥1,5–3 с.
- Вставка начинается уже с движения (рубрика видна, герой в блюре), кончается жёстким резом (full/split-cam) или раскрытием экрана обратно (split-screen/lower).

## 5. Звук (обязателен — автору это нравится больше всего)

Каждое появление графики озвучено. `scenes/NN.sfx.json` = `[[t, "имя"], …]`, не чаще одной кьюшки в 0,3 с.
| Событие | Звук | Уровень |
|---|---|---|
| влёт картинки / панели | `whoosh` | −24 dB |
| смена состояния, push, уход | `whoosh-short` | −24 |
| чип | `pop` | −22 |
| шаг списка | `click` | −20 |
| смена фразы kinetic, мягкий вход | `click-soft` | −21 |
| ключевой акцент, маркер | `ping` | −21 |
| одиночный ввод / счётчик | `key-press` / `typing` | −19 / −16 |
| штамп | `stamp` (assets/style-v4/sfx) | −19 |
| плохой исход | `neg` (assets/style-v4/sfx) | −20 |

Уровни — под тихий голос стрима (пик ≈ −15 dBFS); в первой версии было на 6 dB громче — автор сказал «очень громко». `stamp`/`neg` собраны из **реальных сэмплов** бандла (щелчок клавиши + pop на пониженной скорости + хвост баса; два pop вниз). Синтез из синусов автор забраковал («видно, что сгенерированный»), дефолтные `impact-bass`/`error` — «слишком дефолтные».

Музыка: автор выбирает сам — дать ссылки (Pixabay Music: lo-fi / tech-chill) и рецепт «под водой»: `lowpass=f=750` ×2, −26 dB под голос. В черновик не вшивать.

## 6. План: сколько и где

- Стрим 40 мин → ~30–35 вставок по 8–19 с (≈20–25 % экранного времени), в среднем раз в ~60 с, не чаще раза в 40 с.
- Микс: kinetic 3 (интро + 2 панчлайна), split-cam ~40 %, full ~20 %, split-screen ~25 %, lower ~10 %.
- Вставки — где автор объясняет понятие словами, а экран не помогает. Где идёт живая демонстрация или рисование — split-screen/lower или ничего.
- Список сцен без вставок с причинами — в MOTION.md.

## 7. Пайплайн (как собирали)

Рабочая папка `W` — в `/tmp` / scratchpad, не в montage/. См. `/motion-run` → «Пайплайн v4».
```
W/scenes.json · W/scenes/NN.html (+NN.sfx.json) · W/img/hNN.png · W/clips/{cam,scr}_NN.mp4
python3 scripts/cut_clips.py W source.mp4 [--cam x,y,w,h]
zsh scripts/gen_images.sh prompts.tsv W/raw && uv run --with numpy --with pillow python scripts/alpha.py W/raw W/img
python3 scripts/mk_scene.py W NN     # → W/NN/, потом hyperframes check / render . -o renders/NN.mp4
python3 ../motion-run/scripts/assemble_v4.py W source.mp4 [--intro intro.mp4 --cut SEC]
```

## 8. Приёмка (грабли этой сборки)

- **Принимать по полноразмерному кадру конца сцены**, а не по контакт-листу 3×3 — лист занижает кегль вдвое, и по нему нормальные сцены отправлялись на переделку.
- Типичные настоящие провалы сборщиков: герой ужат в иконку ~120px в углу; половина панели пустая; вторичный текст 18–24px; пустая карточка «{ }» висит секунды; два одинаковых героя подряд.
- Вебку PiP (≈460×260) не растягивать на полкадра — только карточкой ~2,3×.
- `codex exec` в цикле — только с `< /dev/null`. Проверь, что все картинки сгенерированы: иногда safety-отказ на безобидный объект — перефразируй.
- Звук проверять не только пиком: у SFX должна быть энергия выше 300 Гц (`highpass=f=300,volumedetect` ≥ −6 dB), иначе на ноутбуке его не слышно.

## 9. Отступления от design-system.md, которые автор одобрил

- Объёмные фотореалистичные картинки-герои (в DS «без объёма») — да, это суть стиля.
- Эмодзи — только в kinetic, ≥100px.
- Стекло — для `lower` поверх живого экрана (как и разрешает DS: только поверх видео).
