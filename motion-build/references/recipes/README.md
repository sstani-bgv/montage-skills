# Рецепты — рабочие реализации

Десять собранных и принятых композиций. Каждая рендерится, проходит `check` вчистую и лежит
здесь целиком, вместе с вёрсткой и таймлайном.

**Это не шаблоны для копирования целиком.** Композиция сделана под свой контент; если взять её
и подменить тексты, получится чужая сцена с твоими словами. Смотри сюда за другим — как решено
конкретное сложное место. Ниже для каждого рецепта написано, какое именно.

Общее устройство у всех одинаковое: `<link>` на токены → CSS слоёв → разметка с `class="clip"`
и `data-start`/`data-duration` → один `<script>` в конце, где собирается `paused`-таймлайн
и кладётся в `window.__timelines["main"]`. Интересное почти всегда в этом последнем блоке.

| Рецепт | Строк / из них таймлайн | Ради чего смотреть |
|---|---|---|
| `hook-camera-move.html` | 254 / 96 | детерминированный LCG вместо `from:'random'`; раздвижка трекинга через per-glyph `x`; параллакс дочерних слоёв внутри `.camera` |
| `pip-morph.html` | 302 / 99 | **прокси-объект**: один твин `{p}`, из которого в `onUpdate` пересчитываются трансформ, `clip-path` и атрибуты SVG-рамки разом — иначе они разъезжаются |
| `rack-focus-kinetic.html` | 209 / 31 | самый короткий таймлайн из всех; как одновременность расфокуса и первого слова делает приём |
| `chapter-carousel.html` | 313 / 201 | самый сложный: два вложенных враппера (линейный дрейф + прыжки перецентровки), предрасчёт состояний от `|i − active|`, дискретная смена палитры |
| `vertical-push.html` | 247 / 49 | общий рельс вместо двух зеркальных твинов — velocity match по построению |
| `zoom-through.html` | 284 / 89 | параллакс внутри уходящей сцены; зеркальные кривые, когда они **уместны** |

| `icon-arrival-dolly.html` | 233 / 75 | предрасчёт геометрии проезда в константах; blur отдельным, более долгим твином |

## Как читать

1. Начни с `rack-focus-kinetic.html` — там 31 строка таймлайна и видно базовую форму:
   как объявляется `tl`, как кладутся твины, как работает атом появления по словам.
2. Потом `vertical-push.html` — понятно, что такое «связать физически то, что должно
   двигаться вместе».
3. `pip-morph.html` и `chapter-carousel.html` — последними. Там решения, которые без контекста
   выглядят переусложнёнными, а на деле снимают конкретный баг: разъезжающуюся рамку
   и небезопасную перемотку.

Пути к `./assets/tokens.css` в рецептах указаны от корня проекта, а не от этой папки, — они
для запуска в проекте, а не отсюда.
