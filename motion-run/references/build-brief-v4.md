## Как устроена сборка (не init-ить проект руками)

1. Пишешь **фрагмент** `$W/scenes/NN.html` строго в формате:
   ```
   <!-- dur=<секунды из scenes.json> | стрим мм:сс–мм:сс | тезис -->
   <style> …css сцены… </style>
   <body> …разметка внутри #stage… </body>
   <script> …таймлайн сцены… </script>
   ```
2. `python3 $SK/scripts/mk_scene.py $W NN` — собирает проект `$W/NN/` (токены, шрифты, common.css/js, `assets/hero.png` из `$W/img/hNN.png`, клипы `assets/clips/cam_NN.mp4` или `scr_NN.mp4`). Правишь только фрагмент и пересобираешь; `$W/NN/index.html` руками не трогай.
3. `cd $W/NN && $HF check .` — 0 errors. Опт-ауты только по таблице из gotchas.md motion-build.
4. Кадры: `$HF snapshot . --frames 8 -o snapshots` + точечные `--at …` на моментах пересчёта. Смотри глазами через Read, кадр 0 отдельно.
5. Рендер: `$HF render . -o renders/NN.mp4`. Файл остаётся в `$W/NN/renders/`, никуда не копируй.
6. Звук: `$W/scenes/NN.sfx.json` — список `[[t, "имя"], …]` (t от начала сцены, синхронно с появлением на таймлайне). Имена: `whoosh` (влёт картинки/панели), `whoosh-short` (смена состояния, push), `pop` (чип), `click` (шаг списка), `click-soft` (мягкий вход текста, смена фразы в kinetic), `key-press` (одиночный ввод), `typing` (счётчик), `ping` (ключевой акцент, маркер), `stamp` (штамп/удар), `neg` (плохой исход). Не чаще одной кьюшки в 0,3 с; на kinetic — `click-soft` на каждую смену фразы, `whoosh-short` на push.

## Константы стиля

- Кегли: заголовок full 100px; заголовок панели 70–84px; подзаголовок 40–52px; шаги/чипы 30–44px; **ничего мельче 26px** (кроме кикера 24px).
- Один синий акцент на экран; коралл/`#c8322a` — только боль/ошибка; жёлтый `--mark` — маркер за словом.
- Текст опережает голос на 0,15–0,35 с. Слова — `rise` каскадом 0,10–0,15 с. Смена акцента синхронна слову в голосе.
- Двухступенчатый вход (expo.out ~.45 → линейная досадка ~.75). Ничего не стоит: дрейф уже в common.js.
- Панель достраивается: одна панель живёт 10–18 с, к концу полная; холд собранного ≥ 2–3 с.
- Кадр 0: уже есть смысл/движение (кикер виден, картинка в полупрозрачном блюре — как в эталонах).
- Запреты движка: `Math.random`/`stagger:{from:'random'}`, `letterSpacing`-твины, `width/height`-твины (используй scale), `pathLength="1"`, SplitText/FLIP, `repeat:-1`. Стартовые состояния — `gsap.set`.
